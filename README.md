One sentence on a small moment of wonder in everyday life: a shadow reaching the crosswalk half a step before its owner, in a hurry its owner doesn't remember feeling. The program writes that single sentence to `/output/entry.txt` for the make.fun judge — no network, no model call, fully deterministic.

## Run it

```sh
python3 main.py
```
